# Evaluation

The deterministic example's tests cover feedback leading to success, repeated failures, exhaustion, interruption, missing permissions, and a repeated candidate that later passes. Run `python -m unittest discover -s tests -v` to reproduce them.

These are tests of the example's control flow, not an evaluation of the skill's behavior in a language model. No independent model comparison, production integration, cost enforcement, timeout, or token budget test has been performed. Results will vary by agent and task. Contributions with reproducible agent version, task, prompts, output, and evaluation criteria are welcome.
