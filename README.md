# Generate Agentic Loop

A skill for designing and implementing bounded, verifiable agent execution loops. It separates the agent's work cycle from the harness that controls execution, resources, and recovery.

The installable skill is in [`generate-agentic-loop/SKILL.md`](generate-agentic-loop/SKILL.md). Invoke it when designing or improving an agent loop or its harness. Adapt the generated implementation to your environment and validate it before production use.

This is an initial version based on the supplied backbone. Future revisions should be driven by real usage and observed failures.
