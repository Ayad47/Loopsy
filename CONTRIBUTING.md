# Contributing

Report a reproducible use case or limitation in an issue. For a change, explain the problem, provide a small example, and describe how you verified it. Keep the skill concise and avoid claiming support or safety properties without evidence.

Run `python -m unittest discover -s tests -v` for the example. Validate skill frontmatter with the relevant agent's validator when available. Do not include credentials, private logs, or sensitive user data in examples or issues.
